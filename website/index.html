Rokuga for Mac

Every frame, just as it is

Rokuga is a free, native, open-source screen recorder for macOS.

View the source code on GitHub

Screen recording for macOS

  • Record a selected area, full screen, or individual window.
  • Encode H.264 or H.265 video to MP4 or MOV at up to 5K.
  • Match the recording frame rate to the display.
  • Record without time limits or watermarks.

Availability

Rokuga requires macOS 15 Sequoia or later. A signed public build is not available yet.
